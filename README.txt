РАСПИВ — учёт v3

Что нового:
- Аналитика ароматов: продано мл, средняя цена за мл, скорость продаж, проданность, маржа, ROI.
- Три рейтинга: больше всего продано, самая высокая скорость, самая высокая прибыль; отдельный рейтинг по средней цене за мл.
- Окупаемость каждого конкретного флакона.
- Несколько флаконов одного аромата учитываются отдельно.
- Расходники: партия, количество, остаток, цена 1 шт. и автоматическое списание.
- Пример: 12 атомайзеров 5 мл за 305 ₽ = 25,42 ₽/шт; при продаже 5 мл автоматически списывается 1 шт и 25,42 ₽ попадает в себестоимость.
- Списания: пролив, тестер, подарок, личные нужды и т.п.
- Деньги, замороженные в остатках.
- Подсказки по закупкам: когда остаток быстро заканчивается и когда аромат долго лежит.
- Экспорт Excel дополнен аналитикой, остатками расходников и списаниями.
- Штрихкоды убраны из интерфейса, чтобы не усложнять приложение.
- Закрытие окон: крестик, Отмена, Esc и клик по фону.

Важно:
Данные хранятся локально в браузере устройства. Для переноса используйте JSON backup.
Если приложение уже было установлено как PWA, после обновления GitHub Pages может понадобиться закрыть приложение и открыть его заново, чтобы сервис-воркер забрал v3.
