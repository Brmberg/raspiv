РАСПИВ — учёт v8

Что нового:
- Заказы и расходники вынесены на главную.
- Клиенты убраны из интерфейса.
- Нумерация заказов начинается с №0 и идёт автоматически.
- Один заказ может содержать много распивов.
- Каждый распив в заказе привязан к конкретному флакону.
- Можно собрать один заказ из разных ароматов и разных флаконов одного аромата.
- Позиция заказа резервирует объём флакона, пока заказ не завершён.
- При статусе «Завершён» позиции превращаются в продажи: списывается флакон и расходники, считается прибыль.
- Отмена/удаление незавершённого заказа освобождает резерв.
- В распиве есть 3 / 5 / 10 мл и нижняя строка «＋ Флакон» для всего доступного остатка.
- Для заказа также доступно «＋ Флакон — весь доступный остаток».
- Убрана зависимость от клиентов.
- Данные v8 хранятся отдельно: первый запуск чистый для тестирования.

Важно:
Это локальное PWA-приложение. Данные хранятся в браузере устройства. Используй JSON backup для резервной копии.
GitHub Pages только публикует статические файлы и не является сервером базы данных.
