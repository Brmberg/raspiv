РАСПИВ — учёт v5

Что нового:
- Ещё → Расходы / Расходники / Заказы.
- Заказы: статусы «Отправить заказ», «Едет к покупателю», «Уже проданные», «Отменён».
- Даты заказа, отправки и получения.
- Продажи можно фильтровать по статусу заказа.
- Удаление ошибочно добавленных флаконов и расходников с подтверждением.
- Защита от удаления флакона, который уже есть в истории продаж/списаний.
- Кнопка очистки тестовых данных.
- Аналитика и расходники из предыдущей версии сохранены.

Данные:
Эта тестовая версия использует отдельное локальное хранилище raspiv_v5, поэтому при первом запуске начинается с пустой базы. Старые тестовые данные предыдущей версии не удаляются из браузера, но эта версия их не использует.
